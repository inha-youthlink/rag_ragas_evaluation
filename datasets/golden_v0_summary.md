# RAGAS 종합 결과: golden_v0

## 발표용 결과 요약

### 이번 주 진행 흐름

| 단계 | 한 일 | 결과 |
| --- | --- | --- |
| 1. 실제 데이터 적재 | 온통청년 청년정책 API로 정책 데이터를 DB에 적재 | 정책 3,149건 |
| 2. 채점 데이터셋 생성 | DB 정책 문서로 RAGAS `TestsetGenerator`가 질문·정답 쌍 생성 | `golden_v0` 10건 (시험용) |
| 3. 베이스라인 측정 | RAG 연동 없이 순수 LLM(gpt-6-luna)에 질문만 전달, 3회 반복 채점 | 문서 없는 LLM의 기준 점수 확보 |

### 베이스라인 결과 (3회 평균)

| 지표 | 비교 대상 | 점수 | 의미 |
| --- | --- | --- | --- |
| factual_correctness | 채점지 정답(ground_truth) ↔ LLM 답변 | **0.112** | 답변의 사실이 정답과 맞는 정도. 10개 중 약 1개만 맞음 |
| reference_faithfulness | 정책 원문(reference_contexts) ↔ LLM 답변 | **0.126** | 답변이 실제 정책 원문에 근거한 정도. 대부분 원문에 없는 내용 |
| answer_relevancy | 질문 ↔ LLM 답변 (답변에서 거꾸로 만든 질문과 원래 질문의 유사도) | 0.684 | 질문 의도에 맞춰 답한 정도. 주제는 대체로 맞춤 |

### 의미

| 관찰 | 해석 |
| --- | --- |
| 질문 주제에는 맞춰 답함 (관련성 0.68) | LLM은 그럴듯한 답변 형식을 만들어 냄 |
| 사실 정확도는 매우 낮음 (0.11) | 정책명, 지원 규모, 대상 같은 사실을 일반 지식으로 지어냄 → **할루시네이션** |
| 원문 근거도 매우 낮음 (0.13) | 실제 정책 문서를 모르니 **문서에 기반한 답변을 하지 못함** |

**결론**: 순수 LLM만으로는 청년정책 안내에 쓸 수 없다. 실제 정책 문서를 찾아 근거로 넘기는 RAG가 필요하며, 이번 점수가 RAG 성능을 비교할 기준선이다.

**다음 단계**: RAG 연동 후 같은 데이터셋으로 채점해 `rag - baseline` 개선 폭을 확인한다. 정식 평가용 데이터셋(golden_v1)은 검수를 거쳐 건수를 늘린다.

### answer_relevancy (baseline 0.684, offline 0.566)

- 답변에서 질문을 거꾸로 만들어 원래 질문과의 임베딩 유사도를 잰다. 답이 맞는지가 아니라 질문에 맞춰 답했는지를 본다.
- 정답을 넣은 offline이 baseline보다 낮다. 짧은 정답에서 만든 질문이 원래 질문과 표현이 달라지기 때문으로 보인다. 이 지표는 한국어에서 만점이 나오기 어려우므로 절대값보다 모드 간 비교로 본다.
