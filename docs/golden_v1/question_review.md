## 확인해 주실 것

| 항목 | 기준 |
| --- | --- |
| 자연스러움 | 실제 청년 사용자가 할 법한 질문인가 |
| 명확성 | 질문만 보고 어떤 정책을 묻는지 알 수 있는가 |
| 어색함 | "신혼부부 청년으로서…" 같은 앞 문장이 억지스럽지 않은가 |
