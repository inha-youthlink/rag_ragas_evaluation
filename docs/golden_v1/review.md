# golden_v1 검수표

후보 `datasets/golden_candidates.jsonl` 129건을 정책 원문(`reference_contexts`)과 대조한 1차 검토 결과다.
최종 판단 열에 `O`(채택) 또는 `X`(제외)를 적는다. 100건을 채택해 `datasets/golden_v1.jsonl`로 확정한다.

## 요약

| 1차 판정 | 건수 | 의미 |
| --- | --- | --- |
| 유지 | 91 | 원문과 일치, 질문으로 정책 특정 가능 |
| 의심 | 32 | 사용 가능하나 확인 필요 |
| 제외 추천 | 6 | 질문만으로 정책을 특정할 수 없음 |

제외 추천 6건을 빼면 123건이다. 의심 32건 중 23건을 더 빼면 100건이 된다.

## 의심 유형

| 유형 | 내용 |
| --- | --- |
| 모호 | 질문에 지역명이나 정책명이 없어 여러 정책이 해당할 수 있음. 정답 정책만 맞다고 채점되어 RAG가 불리 |
| 페르소나 | 페르소나 설명이 정책과 맞지 않게 질문에 붙음 |
| 시점 | 이미 지난 일정이나 접수 상태에 의존 |
| 원문 없음 | 질문이 원문에 없는 정보를 물음 |
| 정답 문구 / 정답 정확성 | 정답에 메타 문구, 원문 모순·오타가 그대로 반영 |
| 동명 정책 / 유사 정책 | 같은 이름의 다른 정책이 있어 검색 결과 판단이 어려움. 둘 중 하나만 남기는 것을 권장 |
| 단순 | 답이 한 줄이라 변별력이 낮음 |
